## What's new in R1 1.0.2

### Changed
- **AFK no longer reads your position.** AFK still presses the keys for you, but it no longer takes a WHERE AM I read
  about once a minute. The "Read position while AFK" setting is gone.
- **WHERE AM I uses one less OCR reader.** It reads the map's bottom line with the same reader as the info panel, so
  the app runs one less OCR reader and uses about 115 MB less memory.
