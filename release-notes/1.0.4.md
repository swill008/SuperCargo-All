## What's new in R1 1.0.4

### New
- Learned Data: delete entries permanently, or delete and block them so they are not learned again. Blocked items are listed and can be unblocked.

### Changed
- Scanned contracts now list pickup and drop-off as separate steps, the same as contracts read from the game log.

### Fixed
- A pickup named as a place within a city (for example "August Dunlow Spaceport in Orison") now matches that place instead of needing a manual pick.
