## What's new in R1 1.0.0

The first SuperCargo-OtherModes release (release line R1).

### New
- **Other modes.** Track jobs beyond cargo hauling. WHERE AM I reads your position from the screen and names the
  place and planet you're at; the place resolver matches what the game shows to known places; match memory
  remembers places you've confirmed, and the new LEARNED DATA tab shows what the app has learned.
- **Settings in two tabs.** Settings is split into GENERAL and OTHER MODE.
- **One data folder.** Everything the app saves lives in `%USERPROFILE%\SuperCargo-OtherModes`. Settings → GENERAL →
  DATA FOLDER has CHANGE…, OPEN FOLDER and RESET TO DEFAULT. CHANGE… uses the folder you pick as it is (no extra
  folder inside it) and copies your current data in when that folder is empty.
- **Damaged data check.** At start-up, and when you pick a folder with CHANGE…, the app checks its saved files. If
  any can't be read it tells you which ones and why, and offers Reset: all SuperCargo files in that folder are moved
  to a dated folder inside "Moved for Repair" so you can look at them, your settings are kept, and the app starts
  with empty data.
- **Installer and portable zip.** `Setup.exe` installs for your Windows user only (no admin), lets you choose the
  folder, offers an optional desktop shortcut (unticked) and updates itself. `Portable.zip` runs from anywhere and
  tells you when a new version is out.
- **Check for Updates window.** The app checks for a new version at start-up (on by default; turn it
  off with "Check for updates at start-up") and from Settings → GENERAL → UPDATES → CHECK FOR UPDATES. When there
  is one, a window shows what's new in every version since yours, with a link to the full release notes.
- **Update Now, Skip This Version, Later.** Update Now downloads with a progress bar, checks the download is complete
  and unchanged before offering Install and Restart, and Try Again if it fails. Skip This Version keeps the start-up
  check quiet until a newer version comes out. A portable copy offers Open Release Page instead.
- **Updated notice.** After an update, a bar says which version you're now on, with a WHAT'S NEW link.
- **Reference data status.** The Check for Updates window shows the ships, locations, commodities, cargo grids and
  contract box sizes data (from the original SuperCargo author's data): when each file was last checked, whether it
  is up to date, was updated, or couldn't be downloaded or read (the old copy is kept), with a CHECK NOW button.
  Settings → UPDATES warns when any file couldn't be updated.

### Changed
- **Fresh start.** Nothing is read or moved from the folder older SuperCargo builds used (`%APPDATA%\SuperCargo`);
  that folder is left alone.
- **Updates come from swill008/SuperCargo-All.** The version shows as "R1 1.0.0".

### Fixed
- **Overlay card keeps its height.** The stop card in the overlay no longer grows or shrinks when you step between
  stops: long place names are cut with "…" (hover to see the full name) and tags sit on their own line.
- **Reputation ranges.** Contracts that pay a range of reputation, such as "100–500 Rep", are read correctly and shown
  as "+100–500 REP".
- **Altitude when the screen reading is unclear.** When the altitude on screen can't be read, the app works it out
  from your position and the planet's size, so the start label (for example "Hurston · 436 km up") stays right.
- **Place list downloaded once.** At start-up the list of cities, stations and outposts was downloaded twice; it is
  now downloaded once.
