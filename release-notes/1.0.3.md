## What's new in R1 1.0.3

### New
- Settings → General: "OCR time limit" (5-30 seconds, default 10). Raise it if you use a large contract capture area.

### Changed
- Contract scanning and WHERE AM I now share one text reader, reducing memory use by about 115 MB.
- Contract scans take priority: a position read in progress is restarted after the scan.
